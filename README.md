# Personal Expense Tracker

A simple PHP + MySQL web app to track income and expenses, set a monthly budget and view spending charts.

**Live Demo:** https://personal-expense-tracker.42web.io

## Features
- User registration and login
- Add, edit and delete income/expenses
- Monthly budget with warning
- Dashboard with balance and category chart
- Search/filter transactions
- CSV export

## Tech Stack
HTML, CSS, JavaScript, PHP, MySQL, Chart.js

## Deployment
Hosted on InfinityFree (PHP + MySQL free hosting).

## Run on your own computer (optional)
Install XAMPP, import `database.sql` in phpMyAdmin and keep the folder in `htdocs`.

## Note
Never upload real database passwords to GitHub.
